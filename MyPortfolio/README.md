![Portfolio Preview](https://via.placeholder.com/800x400/3B82F6/ffffff?text=Portfolio+Preview)

## 📋 نظرة عامة على المشروع

موقع بورتفوليو شخصي احترافي لمحمد شرشار، مطور ويب بخبرة أكثر من 3 سنوات في تطوير المواقع والتطبيقات. الموقع يعرض المهارات، المشاريع السابقة، والخدمات المقدمة بتصميم عصري وجذاب.

## ✨ الميزات الرئيسية

- **تصميم متجاوب**: يعمل بشكل مثالي على جميع الأجهزة (الهاتف، التابلت، الكمبيوتر)
- **معرض أعمال تفاعلي**: عرض المشاريع بطريقة منظمة وجذابة
- **تأثيرات الحركة**: استخدام مكتبة AOS للتأثيرات البصرية الناعمة
- **قسم المهارات**: عرض تفاعلي للتقنيات والأدوات المستخدمة
- **قسم التواصل**: معلومات الاتصال وروابط وسائل التواصل الاجتماعي
- **تصميم عصري**: ألوان متناسقة وواجهة مستخدم حديثة
- **أداء محسن**: كود نظيف ومحسن للسرعة

## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5**: هيكل الصفحة الرئيسي
- **CSS3**: التنسيق والتصميم مع CSS Variables
- **JavaScript**: التفاعلية والحركة
- **Font Awesome 6.5.1**: الأيقونات
- **AOS 3.0.0**: تأثيرات الحركة عند التمرير

## 🚀 طريقة التشغيل

### الطريقة الأولى: تشغيل مباشر
1. قم بتحميل المشروع
2. افتح ملف `index.html` في المتصفح مباشرة

### الطريقة الثانية: خادم محلي
```bash
# إذا كان لديك Python مثبت
python -m http.server 8000

# أو باستخدام PHP
php -S localhost:8000

# أو باستخدام Node.js
npx http-server
```

### الطريقة الثالثة: XAMPP/WAMP/MAMP
1. ضع المشروع في مجلد `htdocs` أو `www`
2. ابدأ تشغيل الخادم المحلي
3. افتح `http://localhost/MyPortfolio`

## 🔧 التخصيص والتطوير

### إضافة مشروع جديد
1. افتح ملف `index.html`
2. ابحث عن قسم `portfolio-grid`
3. أضف بطاقة مشروع جديدة:

```html
<div class="project-card">
    <div class="project-image">
        <img src="path/to/image.jpg" alt="اسم المشروع">
    </div>
    <div class="project-content">
        <h3>اسم المشروع</h3>
        <p>وصف المشروع</p>
        <a href="رابط_المشروع" class="project-link">عرض المشروع</a>
    </div>
</div>
```

### تعديل الألوان
- قم بتعديل متغيرات CSS في بداية ملف `styles.css`
- يمكن تغيير جميع الألوان من مكان واحد

### إضافة مهارة جديدة
```html
<div class="skillsbox" data-aos="fade-down" data-aos-delay="[الرقم]">
    <img src="./imgs/skill-icon.svg" alt="اسم المهارة">
    <span>اسم المهارة</span>
</div>
```
